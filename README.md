# IQRA WEB STUDIO

Premium, responsive marketing website for **Iqra Web Studio** — a freelance website design business. The site is designed to attract clients and convert visitors into WhatsApp inquiries and website orders.

## Tech Stack
- Pure HTML5, CSS3, and vanilla JavaScript (no build step, no frameworks)
- Google Fonts (Inter + Sora)
- Optimized WebP/JPEG imagery with lazy loading

## Features
- Sticky glass navbar with mobile hamburger menu
- Premium hero with floating website mockup and availability badge
- About highlights, 8 service cards, 3 pricing packages (Starting From)
- Filterable portfolio (all demo projects clearly labeled)
- 4-step process, 12 demo feedback cards, FAQ accordion
- Contact form that composes a pre-filled WhatsApp message
- Floating WhatsApp button (mobile + desktop)
- Dark luxury theme with electric-blue accents and glassmorphism
- Fully responsive (mobile / tablet / desktop) with reduced-motion support

## WhatsApp
All CTAs route to **0329 4228301** (`923294228301`) with context-specific pre-filled messages.
